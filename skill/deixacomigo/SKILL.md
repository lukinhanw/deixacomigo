# deixacomigo

1. Garanta o kit em `~/.deixacomigo`: se não existir, `git clone https://github.com/lukinhanw/deixacomigo ~/.deixacomigo`; se existir, `git -C ~/.deixacomigo pull --ff-only`.
2. Leia `~/.deixacomigo/INSTALAR.md` inteiro e siga o roteiro no projeto atual (a pasta de trabalho), da etapa 0 à 5.
3. Não peça confirmação a cada passo. Nunca leia nem imprima o `.env.local`. Não faça commit sem pedido.
